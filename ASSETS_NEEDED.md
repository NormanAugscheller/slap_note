# Assets needed

SlapNote builds and runs without any of these: placeholders generated by
`swift scripts/make_placeholder_assets.swift` are in the repository. To use a real asset, overwrite the
placeholder file with the **same file name and pixel size**. No code changes are needed. Do **not** run the
placeholder script again afterwards — it overwrites these files.

Note shapes, shadows, the curled corner, the glow and the paper ball are drawn in code and need no bitmaps.

## 1. App icon

Folder: `SlapNote/Resources/Assets.xcassets/AppIcon.appiconset/` (keep `Contents.json` as it is).

| File | Pixels | Used for |
|---|---|---|
| `icon_16x16.png` | 16 × 16 | Finder lists, 1× |
| `icon_16x16@2x.png` | 32 × 32 | Finder lists, 2× |
| `icon_32x32.png` | 32 × 32 | 1× |
| `icon_32x32@2x.png` | 64 × 64 | 2× |
| `icon_128x128.png` | 128 × 128 | 1× |
| `icon_128x128@2x.png` | 256 × 256 | 2× |
| `icon_256x256.png` | 256 × 256 | 1× |
| `icon_256x256@2x.png` | 512 × 512 | 2× |
| `icon_512x512.png` | 512 × 512 | 1× |
| `icon_512x512@2x.png` | 1024 × 1024 | 2×, source image |

Requirements:
- PNG, sRGB, **transparent background** (alpha channel). No pre-rounded "iOS" square — macOS icons are
  free-form or use the macOS rounded-rectangle grid; keep about 10 % transparent margin on every side.
- Create the 1024 × 1024 source once and scale it down (e.g. `sips -z 512 512 source.png --out icon_512x512.png`).
  Check the 16 and 32 px versions by eye; simplify the drawing if it turns to mush.

Suggested prompt (GPT Image):
> A macOS app icon of a single pastel yellow paper sticky note, slightly rotated, with the bottom-right corner
> gently curled up, a soft realistic drop shadow beneath it, and three short hand-drawn dark grey lines of
> "text" on it. Clean, friendly, slightly skeuomorphic style like Apple's own macOS icons. Centered, about 80 %
> of the canvas, transparent background, no border, no text, no letters. 1024 × 1024 PNG with alpha.

## 2. Paper texture (optional)

File: `SlapNote/Resources/paper_texture.png`

Requirements:
- **256 × 256 px** (512 × 512 also works; it is drawn at its point size and tiled).
- **Grayscale**, light (average around 90–95 % white), low contrast — it is multiplied over every note color at
  16 % opacity, so dark or strong patterns would dirty the colors.
- **Seamlessly tileable** on both axes (no visible seams when repeated).
- No alpha needed.

Suggested prompt (GPT Image):
> A seamless tileable texture of fine paper grain, like a matte sticky note seen very close, subtle soft fibers
> and tiny speckles, very light grey on near-white, low contrast, even lighting, no shadows, no folds, no
> vignette, flat top-down, grayscale. 512 × 512, edges must tile seamlessly.

Afterwards make it tileable for sure (e.g. offset by half in an image editor and retouch the seams) and scale
to 256 × 256.

## 3. Menu bar icon — no bitmap needed

The optional menu bar icon uses the SF Symbols `note.text` (normal) and `eye.slash` (notes hidden) as template
images, so it is crisp at every size, adapts to light/dark menu bars automatically and needs no asset.
Generated PNGs rarely work as template icons (they need a pure black shape with alpha at exactly 16 × 16 /
32 × 32 pt). If you want a custom symbol later, draw it as a vector (SF Symbol template or PDF with "Preserve
Vector Data") rather than generating it.
